# exoframe

Host repo for **[ExoFab](https://github.com/Moissanite-Labs/exofab) public intake** — ask what to build, watch it ship.

**Live site:** [https://moissanite-labs.github.io/exoframe/](https://moissanite-labs.github.io/exoframe/)

## What this repo serves

GitHub Pages publishes the static HTML at the repository root (`index.html`, `submit.html`, `queue.html`). A `.nojekyll` file disables Jekyll so visitors see the Crystal Lattice intake UI, not a rendered README.

Design sources, spec, and screenshots live under [`docs/design/public-intake/`](docs/design/public-intake/). See [`docs/design/public-intake/SPEC.md`](docs/design/public-intake/SPEC.md) for product and UX requirements. Prototypes under `docs/design/public-intake/prototypes/` are the design copies; root HTML is the published snapshot for Pages.

## Brand

Use **ExoFab** for the product. **exoframe** is this GitHub host only — not a product name.
